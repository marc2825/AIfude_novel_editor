# 操作ガイド

## 画面とキーボード

中央が本文、上部が作品の操作、右側がAIツールと補助パネルです。狭い画面ではツールが下部に移り、作品の作成や読み込みは「作品操作」にまとまります。

| 操作 | 場所・ショートカット |
|---|---|
| 作品の作成・読み込み・切替 | 上部の操作バーと作品タブ |
| 保存 | 上部の「保存」、Cmd/Ctrl + S |
| AI提案 | 本文を選択して「AI提案」、右クリック、Cmd/Ctrl + K |
| 元に戻す・やり直す | 本文上部の ↶ / ↷、Cmd/Ctrl + Z、対応するRedoキー |
| 検索・置換 | 原稿上部、本文内でCmd/Ctrl + F / H |
| メモリ・章・履歴・診断・組版 | 右側、狭い画面では下部 |
| 全作品のバックアップ・ごみ箱 | 上部の「ファイル」 |
| 作品名・共通プロンプト・文体・モデル | 上部の「設定」 |
| AIの接続先・診断 | 上部の「AI接続」 |

パネルは同じボタン、×、またはパネル内のEscで閉じます。閉じたり別のパネルに切り替えたりしても、入力途中の内容は残ります。「保存」で作品設定・メモ・章設定もまとめて保存できます。

EnterとShift + Enterは、どちらも段落を分けます。貼り付けはプレーンテキストとして扱います。

## 選択した文章を推敲する

右側のAIツールは、目的別に「選択範囲を直す」「カーソル位置に書く」「語句を調べる」の3グループに分かれています（狭い画面では下部の「AIツール」で選びます）。

「選択範囲を直す」のツールを選び、本文から対象の文章を選択します。「AI提案」またはCmd/Ctrl + Kで指示欄を開き、送信する内容を確認して生成してください。ツールはTabと矢印キーでも選べます。

| ツール | 用途 |
|---|---|
| 書き直し | 意味と文体を保ちながら表現を整える |
| 文体変換 | 雰囲気と変換の強さを指定する |
| 膨らませる | 原文にある情報や描写を詳しくする |
| 短くする | 要点を保ちながら冗長な表現を減らす |
| 自由指示 | 保持条件の範囲で、直したい点を自分の言葉で伝える |

候補を切り替えると、その本文と差分を確認できます。「指示・送信設定を変更」から条件を直すこともできます。採用した変更は1回のUndoで戻せます。部分採用では、差分や文を選んで反映する範囲を確認します。

5つの推敲ツールは、人物・出来事・視点・時系列・台詞の意味・事実・固有名詞を保つよう指示します。AIがその条件を守ったかは、原文と差分を読んで確かめてください。「膨らませる」の上限は3,000文字と「原文の2倍＋128文字」の小さい方です。

本文・選択範囲・参照設定を変えると、古い候補は期限切れになります。同じ文章へUndoしても復活しません。ツールを変えた場合はAI画面が閉じるので、対象を選び直して開きます。選択したツールは作品切替では保持され、再読み込みで「書き直し」に戻ります。

## 文章を挿入・補完する

「カーソル位置に書く」のツールを選び、カーソルを置いてから開きます。

| モード | 指定する場所と内容 |
|---|---|
| AI文章挿入 | 推敲ツールで何も選択せずCmd/Ctrl + K。入力したプロンプトから文章を作る |
| 文脈で挿入 | 文中・章の先頭や末尾・空の章にカーソルを置き、書きたい内容を指定する |
| 中間補完 | 前後に本文がある空白だけを選ぶか、途中の空段落にカーソルを置く |
| 続きを書く | 現在の章の末尾にカーソルを置く |
| 描写を足す | 挿入位置で、描きたい対象と焦点（五感・比喩・内面）を指定し、2案以上を比較する |
| 展開を指定 | 挿入位置で次に起こすことを指定し、2案以上を比較する |

補完・文脈挿入の目標文字数は1〜3,000文字、初期値は400文字です。目標と実際の文字数は一致するとは限りません。候補を確認し、採用すると指定した場所に反映されます。

AI文章挿入は、通常は入力プロンプトだけを送ります。補完と文脈挿入は、前後各最大1,000文字（続きは直前のみ）、共通プロンプト、手動の文体設定を参照します。保存済みの作品メモリは、いずれも参照をONにした場合だけ送ります。「描写を足す」「展開を指定」では、新しい描写や事実の追加を許可するかも確認してください。

## 辞書と診断

「語句を調べる」の「辞書」を選び、調べたい語句を1〜100文字選択して開きます。「LLMで調べる」は語句と固定の辞書指示だけを送り、前後本文・作品設定・メモを送りません。「Googleで意味を検索（別タブ）」は語句と「意味」をGoogleへ送ります。AIに接続していなくても検索は使えます。

AIの説明は、出典を確認した辞書とは異なります。デモ応答は実際の語義説明ではありません。辞書の結果を本文に採用する機能はありません。

「診断」では、日本語表現やリズムをPC内で解析します。指摘は確認の手がかりです。無視・再解析・個別修正ができ、修正は差分を確認して「修正を採用」するまで本文に反映されません。AI Feedbackは、指定した章や選択範囲（最大6,000文字）を送る読み取り専用のコメントです。

## 複数のAIを比較する

「AI接続」で比較先を設定し、生成画面で2〜3個を選びます。すべての送信先に同意して「N個のAIへ同時送信」を押すと、同じ入力を各AIへ送ります。

提供元・モデル・候補を見比べ、選んだ候補の差分を確認して採用します。一方が失敗しても、成功した候補は残ります。利用枠やAPI料金は接続先ごとに発生します。

## 作品の設定とメモ

「メモリ」に設定・背景・登場人物を入力して保存します。各欄は最大2,000文字です。生成画面で「保存済み作品メモリを参照する」をONにし、使う項目を選んでください。新しいAIセッションではOFFから始まります。

送るのは保存済みの内容だけです。入力途中のメモや未選択の項目は送りません。入力上限を超えたときは、メモや指示を短くするか参照をOFFにします。メモの更新や参照項目の変更で古い候補は破棄されます。

人物・資料・語彙・文体の設定も作品ごとに保存できます。資料をAIに渡すかは生成時に選びます。メモや設定をAIが自動更新することはありません。

## 作品・章・履歴を管理する

- **新規作品**：空の作品を追加します。作品名は「設定」で変更できます。
- **ファイルを開く**：10MiB以下の作品JSONまたはUTF-8テキストを、新しい作品として開きます。既存作品を上書きしません。
- **作品タブ**：切替前に現在の本文を保存します。タブを閉じても作品は削除されず、保存済み一覧から開き直せます。
- **章とアウトライン**：章の追加・切替・並べ替え・改名・削除と、手入力のアウトラインを保存します。最後の1章は削除できません。
- **保存履歴・復元**：名前付きの記録を最大50件残し、差分を確認して復元できます。復元前の状態も記録されます。自動保存前の履歴記録は作品ごとにONにします（初期OFF）。
- **ごみ箱**：削除した作品・章を最大200件保持します。期限による自動消去はなく、満杯になると削除を中止します。完全削除には確認が必要です。

起動中の作品・章の切替ではUndoとカーソル位置を保持します。再読み込み後は保存した本文とタブを復元しますが、Undo履歴とAI候補は復元しません。

作品の復元で同じIDが使われている場合はコピーを追加します。章の復元は元の作品を開いて行い、編集中の本文を上書きせず新しいIDの章として戻します。

## 保存・読み込み・バックアップ

本文は自動保存されます。「保存」またはCmd/Ctrl + Sでは、入力中の作品設定・メモ・章設定・AI接続設定も保存します。AI接続設定だけ保存できなかった場合は、原稿の保存とは分けて通知します。

| 操作 | 保存・復元する内容 |
|---|---|
| JSONで保存 | 現在の作品の全章・設定・メモ |
| テキスト書き出し | 本文のみ |
| 全作品を一括バックアップ | 全作品・章・メモ・履歴・ごみ箱。100MiBまで |
| 一括復元 | 既存作品を残し、コピーとして追加 |
| 設定内のJSONバックアップ取込 | 確認後に現在の作品を置換。他作品とIDが衝突する場合は拒否 |

読み込んだ作品のAI送信同意とUndo履歴は復元しません。作品JSONは保存形式v6、ブラウザーのDBはv5です。旧形式は読み込み時に移行します。旧アプリへ戻す場合は、更新前のバックアップを使ってください。

未保存の入力がある場合は、作品切替や読み込みなどで破棄するか確認します。キャンセルすれば入力を残します。ブラウザーの終了確認は強制終了や端末障害には対応できないため、重要な原稿はファイルにも書き出してください。

## 検索・文字数・組版

検索対象は現在の章です。1件または全件の置換は、確認後に実行し、1回のUndoで戻せます。検索後に本文を編集したら再検索してください。

文字数は改行を除き、空白を含めてUnicodeコードポイントで数えます。作品ごとに目標文字数を設定できます。

「組版」ではルビ・傍点、縦書きの閲覧、投稿用の出力を扱います。注釈を含む範囲はAIや検索の文字置換を受け付けません。投稿先の記法で表せない内容は、黙って変換せず案内します。

## オフライン・別タブでの利用

オフライン機能は、オンラインのうちに「オフライン利用を準備」して使います。静的な画面だけをキャッシュし、原稿は通常どおりIndexedDBへ保存します。再接続してもAIを自動送信しません。端末やブラウザーが保存領域を削除した場合の復旧は保証できません。

同じURLで編集できるブラウザータブは1つです。2つ目のタブは読み取り専用になります。Web Locksに対応しない環境でも読み取り専用です。

狭い画面ではAI画面の「本文へ」で指示や候補を保持したまま執筆に戻れます。「AI画面に戻る」で再表示してください。本文や選択を変えると候補は期限切れになり、閉じる操作ではセッションを破棄します。
