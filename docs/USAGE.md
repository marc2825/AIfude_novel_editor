# 操作ガイド

## 画面とキーボード

中央が本文です。上部の1行に、作品名のボタン（作品の切替メニュー）、保存状態、AIの実行環境、「保存」があります。左端の列に補助パネルの入口が8つ並び、押したパネルは列のすぐ右に開きます。狭い画面では、この列が画面の下部に移ります。

本文のすぐ上には、章名、検索、元に戻す、やり直す、「AI提案」の細い行があります。章名を押すと「章とアウトライン」が開きます。

AIの使い方は、どのツールでも同じです。

1. 直したい文章を選ぶか、書きたい位置にカーソルを置きます。
2. 「AI提案」、Cmd/Ctrl + K、または選択した文章の右クリックで、AI画面を開きます。
3. AI画面の中でツールを選び、指示を入力して生成します。
4. 候補と差分を読み、「採用」を押します。

採用するまで本文は変わりません。ツールは対象に合わせて出し分けます。文章を選んでいれば「選択範囲を直す」の5つと「辞書」、カーソルだけなら「カーソル位置に書く」の6つです。空白だけを選んだ場合は「中間補完」で開きます。ツールは矢印キーでも選べます。

| 操作 | 場所・ショートカット |
|---|---|
| 作品の作成・読み込み・切替・書き出し | 上部の作品名のボタン |
| 保存 | 上部の「保存」、Cmd/Ctrl + S |
| AI提案 | 本文上部の「AI提案」、右クリック、Cmd/Ctrl + K |
| 語句を調べる | 選択した文章の右クリック →「辞書で調べる」、またはAI画面で「辞書」 |
| 元に戻す・やり直す | 本文上部の矢印、Cmd/Ctrl + Z、対応するRedoキー |
| 検索・置換 | 本文上部の虫眼鏡、本文内でCmd/Ctrl + F / H |
| 章・メモ・診断・履歴・組版 | 左の列（狭い画面では下部） |
| 全作品のバックアップ・ごみ箱・保存済み作品 | 左の列の「作品」 |
| 作品名・共通プロンプト・文体・モデル | 左の列の「設定」 |
| AIの接続先・診断 | 左の列の「AI接続」 |

広い画面（幅1200px以上）では、本文の右にAI用の余白欄があります。AI画面はそこに開き、本文に重なりません。それより狭い画面では、本文の下からトレイやシートとして開きます。AI画面を開いている間は、対象の文章に金色の下地、カーソル位置に金色の縦線が付きます。この印は表示だけで、本文には保存されません。

見出しや項目の横の「?」にカーソルを合わせると、詳しい説明が出ます。タップやTabキーでも開けます。

パネルは同じボタン、閉じるボタン、またはパネル内のEscで閉じます。閉じたり別のパネルに切り替えたりしても、入力途中の内容は残ります。「保存」で作品設定・メモ・章設定もまとめて保存できます。

EnterとShift + Enterは、どちらも段落を分けます。貼り付けはプレーンテキストとして扱います。

## 選択範囲を直す

本文から対象の文章を選択し、「AI提案」またはCmd/Ctrl + KでAI画面を開きます。AI画面の「AIツール」で次のどれかを選び、送信する内容を確認して生成してください。初めは「書き直し」が選ばれています。

| ツール | 用途 |
|---|---|
| 書き直し | 意味と文体を保ちながら表現を整える |
| 文体変換 | 雰囲気と変換の強さを指定する |
| 膨らませる | 原文にある情報や描写を詳しくする |
| 短くする | 要点を保ちながら冗長な表現を減らす |
| 自由指示 | 保持条件の範囲で、直したい点を自分の言葉で伝える |

候補はタブで切り替えます。各候補では、文字数、差分、候補の本文、変更説明、注意事項の順に表示します。AIが返した注意や字面の変化は黄色の枠、採用できない理由は赤の枠で示します。候補の表示中も、「指示・送信設定を変更」からツールや指示を直せます。採用した変更は1回のUndoで戻せます。部分採用では、差分や文を選んで反映する範囲を確認します。

5つの推敲ツールは、人物・出来事・視点・時系列・台詞の意味・事実・固有名詞を保つよう指示します。AIがその条件を守ったかは、原文と差分を読んで確かめてください。「膨らませる」の上限は3,000文字と「原文の2倍＋128文字」の小さい方です。

本文・選択範囲・参照設定を変えると、古い候補は期限切れになります。同じ文章へUndoしても復活しません。AI画面の中でツールを変えると、それまでの候補と通信を捨て、同じ対象で開き直します。対象に合わないツールを選んだ場合は理由を表示し、今の画面と入力を残します。ツールを選ぶだけでは送信しません。

最後に使ったツールは、種類（直す・書く）ごとに覚えます。次に同じ種類の対象で開くと、そのツールから始まります。作品を切り替えても残り、ページを再読み込みすると「書き直し」と「指示から書く」に戻ります。

## カーソル位置に書く

書きたい位置にカーソルを置き、範囲を選ばずにAI画面を開きます。初めは「指示から書く」で開きます。AI画面の「AIツール」で次のどれかを選んでください。覚えているツールがその位置で使えない場合（章の途中で「続きを書く」など）は、「指示から書く」で開きます。

| ツール | 指定する場所と内容 |
|---|---|
| 指示から書く（AI文章挿入） | カーソルを置いて開く。入力したプロンプトから文章を作る |
| 文脈で挿入 | 文中・章の先頭や末尾・空の章にカーソルを置き、書きたい内容を指定する |
| 中間補完 | 前後に本文がある空白だけを選ぶか、途中の空段落にカーソルを置く |
| 続きを書く | 現在の章の末尾にカーソルを置く |
| 描写を足す | 挿入位置で、描きたい対象と焦点（五感・比喩・内面）を指定し、2案以上を比較する |
| 展開を指定 | 挿入位置で次に起こすことを指定し、2案以上を比較する |

補完・文脈挿入の目標文字数は1〜3,000文字、初期値は400文字です。目標と実際の文字数は一致するとは限りません。候補を確認し、採用すると指定した場所に反映されます。

AI文章挿入は、通常は入力プロンプトだけを送ります。補完と文脈挿入は、前後各最大1,000文字（続きは直前のみ）、共通プロンプト、手動の文体設定を参照します。保存済みの作品メモリは、いずれも参照をONにした場合だけ送ります。「描写を足す」「展開を指定」では、新しい描写や事実の追加を許可するかも確認してください。

## 辞書と診断

調べたい語句を1〜100文字選択し、右クリックの「辞書で調べる」を押すか、AI画面の「AIツール」で「辞書」を選びます。「LLMで調べる」は語句と固定の辞書指示だけを送り、前後本文・作品設定・メモを送りません。「Googleで意味を検索（別タブ）」は語句と「意味」をGoogleへ送ります。AIに接続していなくても検索は使えます。

AIの説明は、出典を確認した辞書とは異なります。デモ応答は実際の語義説明ではありません。辞書の結果を本文に採用する機能はありません。

「診断」では、誤字の候補（「をを」のような助詞の重複、同じ漢字語の連続）、語尾や語の反復、長い文、括弧の対応などをPC内で調べます。指摘は確認の手がかりです。無視・再解析・個別修正ができ、修正は差分を確認して「修正を採用」するまで本文に反映されません。

AI Feedbackは、指定した章や選択範囲（最大6,000文字）を送る読み取り専用のコメントです。「確認の種類」で「総合」「誤字脱字」「日本語の自然さ」を選べます。

## 複数のAIを比較する

「AI接続」で比較先を設定し、生成画面で2〜3個を選びます。すべての送信先に同意して「N個のAIへ同時送信」を押すと、同じ入力を各AIへ送ります。

提供元・モデル・候補を見比べ、選んだ候補の差分を確認して採用します。一方が失敗しても、成功した候補は残ります。利用枠やAPI料金は接続先ごとに発生します。

## 作品の設定とメモ

左の列の「メモ」（作品メモリ）に設定・背景・登場人物を入力して保存します。各欄は最大2,000文字です。生成画面で「保存済み作品メモリを参照する」をONにし、使う項目を選んでください。新しいAIセッションではOFFから始まります。

送るのは保存済みの内容だけです。入力途中のメモや未選択の項目は送りません。入力上限を超えたときは、メモや指示を短くするか参照をOFFにします。メモの更新や参照項目の変更で古い候補は破棄されます。

人物・資料・語彙・文体の設定も作品ごとに保存できます。資料をAIに渡すかは生成時に選びます。メモや設定をAIが自動更新することはありません。

## 作品・章・履歴を管理する

- 新規作品：空の作品を追加します。作品名は「設定」で変更できます。
- ファイルを開く：10MiB以下の作品JSON（.json）またはUTF-8テキスト（.txt）を、新しい作品として開きます。既存作品を上書きしません。
- 作品の切替：上部の作品名のボタンを押すと、保存済みの作品の一覧が開きます。開いている作品には印が付きます。別の作品を選ぶと、切替前に現在の本文を保存します。
- 保存済みの作品の管理：切替メニューの「作品を管理」または左の列の「作品」で一覧を開き、作品を開く・ごみ箱へ移す操作ができます。ごみ箱から復元できます。
- 章とアウトライン：章の追加・切替・並べ替え・改名・削除と、手入力のアウトラインを保存します。最後の1章は削除できません。
- 保存履歴・復元：名前付きの記録を最大50件残し、差分を確認して復元できます。復元前の状態も記録されます。自動保存前の履歴記録は作品ごとにONにします。初期値はOFFです。
- ごみ箱：削除した作品・章を最大200件保持します。期限による自動消去はなく、満杯になると削除を中止します。完全削除には確認が必要です。

起動中の作品・章の切替ではUndoとカーソル位置を保持します。再読み込み後は最後に開いていた作品と本文を復元しますが、Undo履歴とAI候補は復元しません。

作品の復元で同じIDが使われている場合はコピーを追加します。章の復元は元の作品を開いて行い、編集中の本文を上書きせず新しいIDの章として戻します。

## 保存・読み込み・バックアップ

本文は自動保存されます。「保存」またはCmd/Ctrl + Sでは、入力中の作品設定・メモ・章設定・AI接続設定も保存します。AI接続設定だけ保存できなかった場合は、原稿の保存とは分けて通知します。

| 操作 | 保存・復元する内容 |
|---|---|
| JSONで書き出す | 現在の作品の全章・設定・メモ |
| テキスト書き出し | 本文のみ |
| 全作品を一括バックアップ | 全作品・章・メモ・履歴・ごみ箱。100MiBまで |
| 一括復元 | 既存作品を残し、コピーとして追加 |
| 設定内のJSONバックアップ取込 | 確認後に現在の作品を置換。他作品とIDが衝突する場合は拒否 |

読み込んだ作品のAI送信同意とUndo履歴は復元しません。作品JSONは保存形式v6、ブラウザーのDBはv5です。旧形式は読み込み時に移行します。旧アプリへ戻す場合は、更新前のバックアップを使ってください。

未保存の入力がある場合は、作品切替や読み込みなどで破棄するか確認します。キャンセルすれば入力を残します。ブラウザーの終了確認は強制終了や端末障害には対応できないため、重要な原稿はファイルにも書き出してください。

## 検索・文字数・組版

検索対象は現在の章です。1件または全件の置換は、確認後に実行し、1回のUndoで戻せます。検索後に本文を編集したら再検索してください。

文字数は改行を除き、空白を含めてUnicodeコードポイントで数えます。作品ごとに目標文字数を設定できます。

「組版」ではルビ・傍点、縦書きの閲覧、投稿用の出力（カクヨム・小説家になろう・pixiv）を扱います。注釈を含む範囲はAIや検索の文字置換を受け付けません。投稿先の記法で表せない内容は、黙って変換せず案内します。pixivはルビだけを「[[rb:親文字 > 読み]]」で出力し、傍点や半角の [ ] を含む原稿は出力しません。

## シークレット作品

他人に見せたくない作品は、「設定」の「シークレット作品」で「この作品をシークレットにする」を押し、パスワードを設定します。パスワードはアプリ全体で1つです。2回目以降は、ほかの作品もボタン1つでシークレットにできます。

シークレット作品は、作品名・本文・章名・アウトライン・作品メモ・執筆設定を暗号化して保存します。保存履歴とごみ箱に残る内容も暗号化します。ロック中は、作品の切替メニューや一覧のタイトルも「シークレット作品」と表示します。

- 上部の「ロック」、または設定の「今すぐロック」ですぐにロックできます。ページの再読み込み時と、10分間操作がないときにも自動でロックします。
- ロック中の作品を開くと、本文の代わりにパスワードの入力欄が出ます。ほかの作品を開いているときは、上部の「解錠」から入力します。
- パスワードを忘れると、誰も（自分も）復元できません。ロック中でも、作品をごみ箱へ移すことはできます。
- 設定の「パスワードを変更」で変えられます。作品の暗号化はそのまま保たれます。

全作品バックアップでは、シークレット作品を暗号化したまま書き出します。別のブラウザーで復元するときは、作成時のパスワードを入力します。単体のJSON・テキスト・投稿用の書き出しは、暗号化されないファイルになることを確認してから行います。シークレット作品は端末同期と移行ファイルを使えません。

章の数・保存日時・保存履歴の名前などは暗号化されません。解錠中は、AIへの送信を含めて通常の作品と同じように使えます。

## オフライン・別タブでの利用

オフライン機能は、オンラインのうちに「オフライン利用を準備」して使います。静的な画面だけをキャッシュし、原稿は通常どおりIndexedDBへ保存します。再接続してもAIを自動送信しません。端末やブラウザーが保存領域を削除した場合の復旧は保証できません。

同じURLで編集できるブラウザータブは1つです。2つ目のタブは読み取り専用になります。Web Locksに対応しない環境でも読み取り専用です。

狭い画面ではAI画面の「本文へ」で指示や候補を保持したまま執筆に戻れます。「AI画面に戻る」で再表示してください。本文や選択を変えると候補は期限切れになり、閉じる操作ではセッションを破棄します。
